## 2. Features

- A bold hero section that puts the "Book Your Cleaning" call to action front and center
- A showcase of the services on offer, from residential and deep cleaning to move-in/out, commercial, post-construction, and carpet & upholstery
- A before & after section so visitors can see the results for themselves
- Trust and guarantee signals that build confidence (insured & bonded, safety-trained staff, eco-friendly, satisfaction guarantee)
- A coverage section showing which cities and areas are served
- Clear, transparent pricing cards with no hidden surprises
- Real customer testimonials with star ratings
- A simple contact and quote request form
- A fully responsive layout that works on any device

## 4. Setup

Project is in `Workspace/cleaning-website/` directory.

```bash
cd Workspace/cleaning-website
npm install
npm run dev       # start the dev server
npm run build     # type-check and build for production
npm run preview   # preview the production build
npm run lint      # lint with oxlint
npm run format    # format with Prettier
```
